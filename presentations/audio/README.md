Put narration recordings here, one folder per deck and one file per chapter:

    audio/science-7min/open.wav
    audio/science-7min/idea.wav
    ...

Formats: WAV, Ogg Vorbis, FLAC or MP3. File names must match the chapter ids
in the deck JSON (see ../SCRIPTS.md). A chapter with audio is timed by its
audio; chapters without audio use their target duration.
